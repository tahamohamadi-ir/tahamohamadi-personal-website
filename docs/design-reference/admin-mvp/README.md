# Approved Admin MVP visual references

These references were approved for the Plan 009 Admin MVP implementation.
They define the visual direction only; the approved backend DTOs and routes
remain the source of truth for every form field and dashboard value.

- `dashboard-desktop.png` — source-backed summary dashboard and navigation
- `blog-editor-desktop.png` — bilingual content editing, lifecycle, and conflict treatment
- `pages-mobile.png` — compact mobile list, filters, translation status, and action placement

Excluded visual concepts: user/role management, backups, analytics charts,
site settings, generic search chrome, and any metric that lacks an existing
Admin API contract.
